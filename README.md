# 🎓 EduResult: Real-Time Student Result Management System

A modern, fast, and responsive web application designed for academic institutions to manage, publish, and search student grades in real time. Built with modern web technologies and powered by a serverless cloud backend.


## 🔗 Live Links

* **Live Demo Website:** [studentresultrecord.netlify.app](https://studentresultrecord.netlify.app/)
---

## ✨ Key Features

* 🔐 **Role-Based Access Control (RBAC):** 
  * **Admin:** Dedicated administrative privileges to publish new student grades and delete existing records.
  * **Student/User:** Read-only access to view and search results securely.
* ⚡ **Real-Time Dynamic Search:** Instant client-side filtering by Student ID, Student Name, or Course Code without reloading the page.
* 🛡️ **Secure Authentication:** User registration and login handled securely via Firebase Authentication SDK v10.8.0.
* 📊 **Cloud Database:** Real-time data synchronization utilizing Google Cloud Firestore (NoSQL).
* 🎨 **Modern Dark UI:** Responsive and sleek dark-themed layout built with Bootstrap 5 and custom CSS styling.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, Bootstrap 5.3.0
* **Scripting & Architecture:** JavaScript (ES6 Modules)
* **Authentication Engine:** Firebase Authentication
* **Backend & Database:** Google Cloud Firestore (NoSQL)
* **Hosting / Deployment:** Netlify
